# RepoLearn Agent Contract

RepoLearn owns only the portable human-judgment learning layer: learning interaction policy, learning evidence schemas, assessment helpers, state-backend contracts, client installation projections, repository-context adapters, and evaluation instrumentation.

RepoLearn does not own or alter target-repository authority, routing, worker/model selection, verification, acceptance, merge, release, deployment, security, or production gates. Learning failure must degrade to normal engineering, not block engineering.

Personal learning state has exactly one canonical owner at a time. Adapters and caches are projections only and must not become a second mastery source of truth. Cross-repository learning may transfer abstract principles and capability evidence, but must not copy private source material across workspace or organization boundaries without explicit authorization.

Keep V1 small. Do not add a server, database service, daemon, cloud control plane, dashboard, vector database, knowledge graph, coding runtime, router, or model gateway without a separate evidence-backed decision.

For behavior changes, run focused tests and `git diff --check`. Do not self-authorize release or publication beyond the exact change requested.
