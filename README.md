# RepoLearn

RepoLearn is a portable learning layer for AI-assisted software development. Its purpose is to help developers preserve and strengthen system-architecture judgment while continuing to use AI for implementation and analysis.

V1 focuses on a small set of contracts: user-owned learning evidence, low-interruption trigger policy, conservative assessment, delayed transfer, portable Agent Skills content, and thin repository context adapters.

RepoLearn is deliberately non-authoritative: it never changes a repository's engineering authority, routing, verification, acceptance, merge, release, security, or production gates. If RepoLearn is unavailable, normal engineering continues.

The first dogfood user is James across the Nexus repository family. Until an explicit migration transaction occurs, James's canonical personal-learning state remains the existing Nexus Owner-learning Ledger; RepoLearn must consume it through an adapter rather than create a second mastery SSOT.

Status: early V1 contract bootstrap. No learning-effectiveness claim is made yet.
